# Getting help

Thanks for using **auto-maintainer-framework**. Here is where to go depending on
what you need.

## Bugs and feature requests

Please use [GitHub issues](https://github.com/changyu87/auto-maintainer-framework/issues)
to report a bug or request a feature. Before opening a new issue, search the
existing ones in case it has already been reported.

When filing a bug, it helps to include:

- what you expected to happen and what actually happened,
- the steps to reproduce it, and
- relevant versions (Claude Code, the plugin, and the `gh` CLI).

## Design and "how does this work?" questions

For design background, architecture, and conceptual questions, start with the
[`docs/`](docs/) folder:

- [`docs/DESIGN.md`](docs/DESIGN.md) — the design and architecture.
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — per-feature status and what's planned.
- [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md) — fixes for common problems.

If the docs don't answer your question, open a GitHub issue and we'll help.
